How it loads
Read-only GET through one named public relay: r.jina.ai, Jina AI's Reader service (a documented, free, rate-limited product). The relay sees the team ID in the request URL, like any site you visit. No login, no keys, nothing is written back. If the relay is down or its free terms change, loading fails loudly - it never falls back to a second operator without telling you.
